# EEG2Video Repository Structure

This document provides a comprehensive overview of the EEG2Video repository structure and the purpose of each component.

## 📁 Top-Level Directory Structure

```
EEG2Video/
├── EEG_preprocessing/    # EEG signal preprocessing tools
├── EEG-VP/              # EEG-VP benchmark code
├── EEG2Video/           # Main EEG2Video framework
├── dataset/             # Dataset organization and metadata
├── assets/              # Demo videos and images
├── requirements.txt     # Python dependencies
└── README.md           # Main project README
```

## 🧠 EEG_preprocessing/

**Purpose**: Tools for preprocessing raw EEG signals into features suitable for video reconstruction.

**Contents**:
- `segment_raw_signals_200Hz.py` - Segments raw EEG signals sampled at 200Hz
- `extract_DE_PSD_features_1per1s.py` - Extracts Differential Entropy (DE) and Power Spectral Density (PSD) features with 1-second windows
- `extract_DE_PSD_features_1per2s.py` - Extracts DE/PSD features with 2-second windows
- `DE_PSD.py` - Core functions for DE and PSD feature extraction

**Key Features**:
- Processes raw 62-channel EEG signals recorded at 200Hz
- Extracts frequency-domain features (DE and PSD) in different frequency bands
- Segments signals into appropriate time windows for analysis

## 🏆 EEG-VP/

**Purpose**: EEG Visual Perception (EEG-VP) benchmark for evaluating EEG-based visual understanding models.

**Contents**:
- `EEG_VP_train_test.py` - Training and testing script for the benchmark
- `models.py` - Neural network models for the benchmark tasks

**Description**: 
The EEG-VP benchmark evaluates models on various visual perception tasks using EEG signals, including:
- Visual object recognition
- Scene understanding
- Motion perception
- Other low-level and high-level visual features

## 🎬 EEG2Video/

**Purpose**: Main framework for reconstructing videos from EEG signals.

### Directory Structure

```
EEG2Video/
├── EEG2Video_New/           # New version of EEG2Video (recommended)
│   ├── Semantic/            # Semantic predictor module
│   ├── Seq2Seq/             # Sequence-to-sequence latent predictor
│   ├── DANA/                # Diffusion-based Adaptive Noise Addition
│   └── Generation/          # Video generation module
├── models/                  # Model architectures
├── pipelines/              # Inference pipelines
├── configs/                # Configuration files
├── train_finetune_videodiffusion.py  # Training script
└── inference_eeg2video.py  # Inference script
```

### EEG2Video_New/ (Latest Version)

The new version is modular and consists of four main components:

#### 1. Semantic/ - Semantic Predictor
- **File**: `eeg_text.py`
- **Purpose**: Maps EEG features to text embeddings
- **Model**: CLIP-style model with MLP architecture
- **Input**: 310-dimensional EEG features (62 channels × 5 frequency bands)
- **Output**: 77×768 dimensional text embeddings (CLIP text embedding space)

#### 2. Seq2Seq/ - Latent Space Predictor
- **File**: `my_autoregressive_transformer.py`
- **Purpose**: Predicts video latent representations from EEG signals
- **Architecture**: Transformer-based autoregressive model
- **Function**: Generates initial latent codes for the video diffusion model

#### 3. DANA/ - Diffusion-based Adaptive Noise Addition
- **File**: `add_noise.py`
- **Purpose**: Adds adaptive noise to latent codes to improve video quality
- **Method**: Uses diffusion process to refine latent representations
- **Benefit**: Helps the model better capture temporal dynamics

#### 4. Generation/ - Video Generation
- **Base**: Built on Tune-A-Video framework
- **Purpose**: Generates videos from EEG-derived embeddings
- **Key files**:
  - `train_finetune_videodiffusion.py` - Fine-tunes video diffusion model
  - `inference_eeg2video.py` - Runs inference to generate videos
  - `models/` - UNet3D, attention mechanisms, semantic predictor
  - `pipelines/` - Custom pipelines for EEG-to-video generation

### Legacy EEG2Video Components

The root `EEG2Video/` directory contains the original implementation:
- `models/` - Original model architectures (UNet, attention, DANA module)
- `train_finetune_videodiffusion.py` - Original training script
- `inference_eeg2video.py` - Original inference script

## 📊 dataset/

**Purpose**: Dataset metadata and organization information for the SEED-DV dataset.

**Contents**:
- `meta_info/` - Metadata files for EEG-VP benchmark
  - `All_video_label.npy` - Video category labels
  - `All_video_color.npy` - Color information
  - `All_video_face_appearance.npy` - Face appearance features
  - `All_video_human_appearance.npy` - Human appearance features
  - `All_video_obj_number.npy` - Object count information
  - `All_video_optical_flow_score.npy` - Motion information
- `BLIP/` - Video captions generated by BLIP model (for 7 sessions)
  - `1st_10min.txt` through `7th_10min.txt` - Captions for each session
- `channel-order.xlsx` - EEG channel naming and ordering
- `channel_62_pos.locs` - 62-channel electrode positions

## 🎨 assets/

**Purpose**: Contains demonstration materials.

**Contents**:
- `origif/` - Ground truth video clips
- `recgif/` - Reconstructed video clips by EEG2Video
- `galaxy_brain.gif` - Project mascot

## 🔗 Component Relationships

```
Raw EEG Data
    ↓
[EEG_preprocessing] → Preprocessed EEG Features (DE/PSD)
    ↓
[EEG-VP] → Benchmark evaluation (optional)
    ↓
[EEG2Video/Semantic] → Text Embeddings
    ↓
[EEG2Video/Seq2Seq] → Initial Latent Codes
    ↓
[EEG2Video/DANA] → Refined Latent Codes
    ↓
[EEG2Video/Generation] → Reconstructed Videos
```

## 📦 Model Dependencies

The framework uses several pre-trained models:
- **Stable Diffusion v1.4** - Base video generation model
- **CLIP** - Text embedding space for semantic alignment
- **Tune-A-Video** - Video diffusion fine-tuning framework

- `requirements.txt` - All Python package dependencies
- `README.md` - Main project documentation with demos and citations
- Configuration files (`.yaml`) - Training and inference parameters
- Pre-trained model checkpoints (to be downloaded separately)
